# Dayflow - HRMS (Nmit Hackathon)

Dayflow is a lightweight HRMS dashboard prototype for the employee experience.

## Run locally

Open [index.html](index.html) directly in a browser. No build step or dependencies are required.

The prototype includes responsive dashboard, attendance, leave requests, people, payroll, profile, and settings views. The leave request form is interactive and displays a confirmation toast on submission.
